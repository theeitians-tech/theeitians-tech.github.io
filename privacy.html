Privacy policy

Last updated: November 16, 2026

What this app is

Clip Uploader is a personal tool used only by its owner to upload videos to the owner's own YouTube channel. It isn't offered to the public.

What data it uses

When the owner signs in with Google, the app receives permission to manage that one YouTube channel. It uses this permission only to upload videos, set their titles, descriptions and tags, and check each video's processing status so it can be made public.

It stores the resulting sign-in token on the owner's own computer. It doesn't collect, store or process information about anyone else.

Sharing

No data is sold, shared with third parties or used for advertising. Data from Google APIs is used only as described above, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

The owner can revoke the app's access at any time at myaccount.google.com/permissions, and delete the token stored on their computer.
